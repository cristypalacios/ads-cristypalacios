CRISTY PALACIOS STUDIO — Landing de anuncios (ads.cristypalacios.com)
========================================================================

CÓMO VER LA PÁGINA AHORA MISMO (sin internet, sin instalar nada)
------------------------------------------------------------------
1. Descomprime este ZIP en cualquier carpeta de tu computadora.
2. Haz doble clic en el archivo "index.html".
3. Se abre en tu navegador. Revisa los textos, las fotos, y prueba
   achicando la ventana para ver cómo se ve en celular.
4. Los botones de WhatsApp SÍ funcionan en local (abren WhatsApp Web
   o la app). El Pixel de Meta NO se puede probar en local — eso se
   verifica después de publicar, es normal.

QUÉ HAY DENTRO
------------------------------------------------------------------
index.html         La página principal (todo: HTML, CSS y JS en un solo archivo)
privacidad.html     Aviso de privacidad (obligatorio por el Pixel de Meta)
sitemap.xml         Mapa del sitio para Google
robots.txt          Indica a Google que puede indexar la página
images/             Todas las fotos, el logo y el favicon ya optimizados

CUANDO ESTÉS LISTA PARA PUBLICAR (deploy)
------------------------------------------------------------------
Este es el siguiente paso, y lo hacemos juntos en el chat cuando
apruebes cómo se ve la página. En resumen: sube esta carpeta a un
repositorio de GitHub, conecta ese repositorio a Netlify (gratis),
y conecta el subdominio ads.cristypalacios.com desde Hostinger a
Netlify. Ningún paso de este proceso requiere que compartas
contraseñas ni tokens conmigo — tú los pegas directo en cada
plataforma.

antes de publicar. Corregir ahora es gratis; corregir después de
publicar también se puede, solo toma un poco más de pasos.
